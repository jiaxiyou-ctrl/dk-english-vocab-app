# DK 英语 10000 词互动单词书

把图解单词书变成一个可以点读、遮蔽、自测的轻量网页应用。

[在线打开](https://jiaxiyou-ctrl.github.io/dk-english-vocab-app/) · [查看源码](https://github.com/jiaxiyou-ctrl/dk-english-vocab-app)

## 为什么做这个

纸质单词书适合系统浏览，但它有几个明显的不方便：不能直接听发音，复习时需要手动遮中文，学习进度也只能靠自己记。

这个项目保留图解单词书最有价值的部分：**按场景组织词汇，用图片建立记忆线索**。在此基础上加上网页交互：点击英文就能听发音，需要自测时可以遮住中文，学过哪些词也会自动记录。

它的定位很简单：不是课程，不是打卡软件，也不是复杂的背词系统，而是一本更顺手的互动单词书。

## 核心功能

### 图文对照

学习页保持左图右词表的结构。左边看原书图片，右边看整理后的中英文词表。图片负责提供场景，词表负责快速点读和复习。

### 点击发音

点击英文单词即可朗读。发音来自浏览器内置的 Web Speech API，不需要额外安装插件。

### 中文遮蔽

打开“遮蔽中文”后，中文释义会被模糊处理。点击单词后，当前词的中文会显示出来。这个模式适合快速自测，但不会制造沉重的复习任务。

### 轻量进度

系统会记录点读过的单词，并在首页显示每个主题的学习进度。复习提示只做温和提醒，不按复杂遗忘曲线强制排任务。

### 本地保存

学习记录保存在浏览器本地。换设备、换浏览器或清理浏览器数据后，进度不会自动同步。

## 适合怎么用

- 每天选一个感兴趣的主题，快速看图点读 5-10 分钟
- 第一次学习时打开中文，对照图片建立印象
- 第二次回看时打开中文遮蔽，先回忆再揭示
- 不追求一次背完，适合碎片时间反复翻看

## 本地运行

```bash
python3 -m http.server 8080 --directory app
```

然后打开：

```text
http://localhost:8080
```

如果想让手机访问本地版本，需要手机和电脑连接同一个 Wi-Fi，再用手机打开电脑的局域网地址。

## 项目结构

```text
app/
  index.html          # 网页入口
  css/style.css       # 页面样式
  js/app.js           # 路由和数据加载
  js/home.js          # 首页
  js/learn.js         # 学习页
  js/progress.js      # 本地进度
  js/speech.js        # 发音
  data/               # 主题和词汇数据
  assets/images/      # 页面图片
scripts/
  audit_data.py       # 数据校验脚本
  extract_all.py      # 页面和索引提取脚本
```

## 数据校验

项目提供了一个轻量校验脚本，用于检查主题数量、词数、图片路径和索引一致性：

```bash
python3 scripts/audit_data.py
```

当前校验结果：

- 180 个主题
- 9,757 个词汇条目
- 0 个缺失图片引用
- 0 个索引错误

## 后续打磨方向

优先级会放在让这本单词书更准确、更好看、更顺手：

- 持续校对词表和图片对应关系
- 优化移动端阅读体验
- 增加关键词搜索
- 增加收藏词功能
- 增加学习记录导出和导入

暂时不会加入复杂打卡、排行榜或强制复习任务。这个项目更适合轻松翻看和高频接触，而不是把学习变成负担。
