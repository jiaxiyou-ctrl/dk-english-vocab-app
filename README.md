# DK 英语 10000 词互动学习网页

这是一个面向个人学习的英语词汇网页应用，基于《DK 中英双语 10000 词》的主题结构整理。应用保留原书的图像化学习方式，同时加入点击发音、中文遮蔽、自测复习和学习进度记录，适合在电脑、平板和手机浏览器中使用。

在线访问：

[https://jiaxiyou-ctrl.github.io/dk-english-vocab-app/](https://jiaxiyou-ctrl.github.io/dk-english-vocab-app/)

## 项目内容

应用目前整理了全书主要主题内容：

- 180 个主题单元
- 14 个大类
- 约 9,700 个词汇条目
- 对应主题页图片
- 每个单词支持点击发音
- 学习记录保存在当前浏览器本地

## 主要功能

### 图文对照学习

每个主题页面左侧显示原书图片，右侧显示对应词汇列表。用户可以一边看图，一边点击右侧单词听英文读音。

### 点击发音

应用使用浏览器自带的语音合成功能。点击英文单词后，浏览器会自动朗读该单词。发音功能可以在学习页顶部手动关闭。

### 中文遮蔽

学习页提供中文遮蔽开关。开启后，中文释义会先隐藏，点击单词后再显示。这个模式适合复习和自测。

### 学习进度

点击过的单词会被记录为已学习。首页会显示各主题的学习进度，并根据最近学习时间给出简单的复习提示。

### 手机使用

网页已经发布到 GitHub Pages，可以直接用手机浏览器打开。iPhone 用户可以通过 Safari 的“添加到主屏幕”功能，把它作为一个快捷入口使用。

## 使用方式

### 在线使用

直接打开：

[https://jiaxiyou-ctrl.github.io/dk-english-vocab-app/](https://jiaxiyou-ctrl.github.io/dk-english-vocab-app/)

建议使用 Chrome、Safari 或 Edge 的较新版本。语音朗读依赖浏览器支持，不同设备上的发音效果可能略有差异。

### 本地运行

如果需要在电脑本地查看，可以在项目目录中运行：

```bash
python3 -m http.server 8080 --directory app
```

然后打开：

```text
http://localhost:8080
```

如果希望手机访问本地版本，需要让手机和电脑连接同一个 Wi-Fi，并在手机浏览器中打开电脑的局域网地址，例如：

```text
http://电脑局域网IP:8080
```

## 技术说明

项目使用原生前端技术实现：

- HTML
- CSS
- JavaScript
- Web Speech API
- localStorage
- GitHub Pages

整个应用是静态网页，不需要后端服务。学习进度保存在用户自己的浏览器中，清理浏览器数据或更换设备后，进度不会自动同步。
