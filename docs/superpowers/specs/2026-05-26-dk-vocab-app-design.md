# DK中英双语10000词 互动发音 Web App — 设计文档

## 项目概述

将《DK中英双语10000词》扫描版PDF（402页，100个主题单元）转化为一个可交互的Web App。用户点击单词即可播放英文发音，支持中文遮蔽自测和学习进度追踪。

**原型范围：** 先实现"01 身体各部分"主题（第13-14页，约2-3页内容），验证交互体验后再扩展。

## 技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 平台 | Web App (PWA) | 零成本部署，跨设备访问，免上架费 |
| 发音 | Web Speech API (SpeechSynthesis) | 免费，离线可用，零外部依赖 |
| 数据存储 | localStorage | 个人使用足够，无需后端 |
| 部署 | 静态托管 (GitHub Pages / Vercel / 本地) | 免费，无服务器成本 |
| 前端框架 | 原生HTML/CSS/JS 或轻量框架 | 原型阶段保持简单 |

## 数据准备流程

1. **提取页面图片：** 用PyMuPDF从PDF中导出每页的扫描图片
2. **OCR提取文字：** 对每页图片进行OCR，提取英文单词和中文翻译
3. **人工校正：** 检查OCR结果，修正错误识别
4. **结构化数据：** 整理为JSON格式，每个主题一个数据文件

## 页面设计

### 1. 主页 (Home)

**布局：**
- 顶部：App标题
- 主体区域分两个板块：

**复习提醒板块：**
- 按上次学习时间对主题进行颜色分组聚合：
  - 绿色：3天内学习过（状态良好）
  - 黄色：3-7天未复习（建议复习）
  - 红色：7天以上未复习（急需复习）
  - 灰色：尚未开始学习
- 点击任意主题卡片直接进入学习页

**全部主题板块：**
- 按大类（人、外貌、家庭、城市、食物等）分组展示
- 每个主题卡片显示：主题编号、标题（中/英）、学习进度条（已学单词数/总数）
- 点击进入对应主题的学习页

### 2. 学习页 (Learn)

**整体布局：** 左右分栏

**左侧 — 图片展示区：**
- 显示原书扫描页面图片
- 纯展示，不做交互
- 如果一个主题包含多页，支持上下滚动或翻页切换

**右侧 — 单词列表栏：**

顶部控制区（固定不滚动）：
- 主题下拉导航：显示当前主题名称，下拉可快速切换到其他主题
- 遮蔽开关：toggle按钮，默认关闭（显示中文翻译）
- 发音开关：toggle按钮，默认开启（点击单词自动播放发音）

单词列表区（可滚动）：
- 每个单词为一个卡片/行，显示：
  - 编号
  - 英文单词
  - 中文翻译（受遮蔽开关控制）

**交互逻辑：**

| 遮蔽 | 发音 | 点击单词效果 |
|------|------|------------|
| 关 (显示翻译) | 开 | 播放英文发音 |
| 关 (显示翻译) | 关 | 无效果（快速浏览模式） |
| 开 (隐藏翻译) | 开 | 显示该词中文翻译 + 播放发音 |
| 开 (隐藏翻译) | 关 | 仅显示该词中文翻译 |

遮蔽模式下，已揭开的翻译保持显示，不会自动隐藏。关闭遮蔽开关时重置所有单词为显示状态，再次开启遮蔽时全部重新隐藏。

## 学习进度管理

### 数据模型

```json
{
  "topics": {
    "01": {
      "learnedWords": [1, 2, 3, 5],
      "totalWords": 25,
      "lastStudyDate": "2026-05-26",
      "studyCount": 3
    }
  }
}
```

### 进度记录规则

- 用户在学习页点击过的单词标记为"已学习"
- 进入学习页时自动更新 `lastStudyDate`
- 进度数据存储在 `localStorage` 中，key为 `dk-vocab-progress`

## 响应式设计

- **桌面端（>768px）：** 左右分栏，左图片右单词列表
- **移动端（≤768px）：** 上下布局，上方图片（可折叠）、下方单词列表全屏宽度
